# lucky-anchor-kit



给自己省点事的小工具

## 用法

```bash
cat data.txt | python main.py
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 备注

就是给自己省点事，没做太多抽象。

## 安装

```bash
git clone https://github.com/USER/lucky-anchor-kit.git
cd lucky-anchor-kit
pip install -r requirements.txt
```
